INSTALLATION — MDT V5 FINAL

1. Ouvrir le dossier mdt dans le dépôt GitHub.
2. Supprimer uniquement le contenu de ce dossier mdt.
3. Importer tout le contenu du dossier MDT-V5-FINAL, y compris le sous-dossier images.
4. Vérifier que index.html, mdt-v5.css et nav-v5.js se trouvent directement dans mdt.
5. Valider les changements sur la branche main.
6. Attendre que le déploiement Vercel affiche Ready.
7. Ouvrir le MDT dans une fenêtre de navigation privée pour éviter l'ancien cache.

Cette version n'utilise plus nav.css, nav.js ou theme.css.
La page Divisions a été retirée.
Les fichiers d'authentification, les API et le bot Discord ne doivent pas être modifiés.
