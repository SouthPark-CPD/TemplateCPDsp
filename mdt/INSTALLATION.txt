INSTALLATION V5

1. Ouvrir le dossier mdt dans le dépôt GitHub.
2. Supprimer tout son ancien contenu.
3. Importer tout le contenu de ce dossier MDT-V5, sous-dossier images compris.
4. Vérifier que index.html, mdt-v5.css et nav-v5.js se trouvent directement dans mdt.
5. Valider les changements sur la branche main.
6. Attendre que le nouveau déploiement Vercel indique Ready.
7. Ouvrir le site dans une fenêtre de navigation privée.

Cette version n'utilise plus nav.css, nav.js ou theme.css.
La page Divisions est retirée.
